# craftedge

Craft structured JSON edge payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/craftedge/

## Install / run

```bash
git clone https://github.com/theworker02/craftedge.git
cd craftedge
node src/cli.js
node --test
```
